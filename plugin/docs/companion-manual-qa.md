# 陪伴窗实机验收清单（与自动化分开记录）

自动化：`cd plugin && npm test`。桌面 Chrome 预览不能代替下面的真机记录。

预览挂的是陪伴窗本身（胶囊 / 浮卡 / 完整对话 / 键盘），全屏聊天要显式打开 `#chat`。

## Mac

- [ ] 胶囊停在右下角，可以拖动；点胶囊只打开浮卡，不弹键盘、不请求模型
- [ ] 有选区时浮卡靠选区，不盖住被引用的文字；没有选区时停在底部，且没有指向
- [ ] 点输入或展开进入完整对话；点收起先回浮卡，再收起成胶囊；点笔记正文回到胶囊
- [ ] 切换笔记只更新上下文标记，零次模型请求
- [ ] 全屏工作区时陪伴层隐藏；返回笔记后草稿、滚动位置和生成都还在
- [ ] A 笔记发问后切 B，回复仍锚定 A；版本变化后「插入/替换」被拒绝
- [ ] 生成中收起、再展开、进入全屏，回复不断、不重复；停止就是发送按钮变成的停止

## iPhone

同一台手机对照留下四张：阅读态、输入态、候选栏展开态、键盘收起态。确认加载的是这次构建。

- [ ] 胶囊在底栏上方；有回复只出轻提示，不自动展开；点胶囊不弹键盘
- [ ] 浮卡不是固定 60% 半屏。选区靠近顶部或底部时不越界、不挡住引用；长回复在浮卡里最多约四行，展开后才是完整对话
- [ ] 键盘：中文拼音、候选栏展开、英文、表情、多行输入、反复开合、横竖屏。输入文字和发送按钮始终完整可见，输入栏底部距键盘约 8px，没有第二份位移
- [ ] 键盘收起后仍停在完整对话，笔记回到打开前的位置
- [ ] 宽度 375 / 393 / 430、明暗主题、安全区；标题是 Agent 名称，模型在「更多」里
- [ ] 配对后 Mac 发消息，手机打开接续；手机有草稿时不被远端抢走

## 离线 / 恢复

- [ ] 离线发送先入队；unknown 不盲目重发；锁屏/重启/服务恢复后消息不丢不重
